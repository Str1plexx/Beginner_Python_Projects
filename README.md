## 📌 О проекте

В репозитории собраны практические консольные мини-игры, разработанные в рамках курса «Поколение Python: курс для начинающих» (Stepik). Проекты направлены на закрепление базовых алгоритмических структур: циклов, ветвлений, списков, функций и генератора псевдослучайных чисел.

### 1. 🎯 «Числовая угадайка» (`pick_a_number.py`)
Интерактивная игра, в которой программа загадывает случайное число в заданном пользователем диапазоне, а игрок пытается его угадать.
- **Настраиваемый диапазон:** верхняя граница загадываемого числа задается пользователем.
- **Валидация диапазона:** проверка корректности ввода числа.
- **Подсказки:** подсказки в процессе («Выбранное число меньше / больше загаданного»).
- **Счётчик попыток:** фиксация номера текущей попытки.
- **Быстрый выход:** возможность досрочно прервать раунд вводом `-1`.
- **Игровой цикл:** предложение сыграть заново без перезапуска программы.

### 2. 🎱 «Магический шар 8» (`magic_ball_8.py`)
Консольный оракул судьбы Magic 8 Ball, выдающий случайные ответы на любые вопросы.
- **Пул ответов:** 20 классических вариантов (положительные, нейтральные, отрицательные).
- **Случайный выбор:** выборка предсказания через генератор псевдослучайных чисел.
- **Диалоговый цикл:** возможность задавать вопросы подряд с выходом по слову «Нет».

## 🚀 Быстрый старт и запуск

Для запуска не требуется установка сторонних библиотек:

### 1. Клонирование репозитория
```bash
git clone git@github.com:Str1plexx/Beginner_Python_Projects.git
cd Beginner_Python_Projects
```

### 2. Запуск игры «Числовая угадайка»
```bash
python3 pick_a_number.py
```

### 3. Запуск «Магического шара»
```bash
python3 magic_ball_8.py
```
