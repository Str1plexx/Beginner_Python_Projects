    ## 📌 О проектах

    В репозитории собраны первые практические мини-игры, написанные для
  закрепления работы с циклами, ветвлениями, функциями и генератором
  псевдослучайных чисел:

    ### 1. 🎯 «Угадайка чисел» (`pick_a_number.py`)
    Интерактивная игра, в которой программа загадывает случайное число в
  диапазоне от 1 до 100, а пользователь пытается его отгадать.
    * **Ключевые фичи:**
      * Валидация пользовательского ввода (защита от падения при вводе строк
  или чисел вне диапазона).
      * Подсказки пользователю («Слишком мало», «Слишком много»).
      * Подсчет количества попыток.
      * Возможность сыграть повторно без перезапуска скрипта.

    ### 2. 🎱 «Магический шар 8» (`magic_ball_8.py`)
    Консольный аналог знаменитого предсказателя судьбы Magic 8 Ball.
    * **Ключевые фичи:**
      * Индивидуальное приветствие пользователя по имени.
      * Пул классических ответов (положительные, нерешительно-положительные,
  нейтральные, отрицательные).
      * Случайная выборка ответов с помощью функции `random.choice()`.
      * Интерактивный цикл вопросов с возможностью выхода.
